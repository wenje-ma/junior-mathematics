# Junior Mathematics (Junior-High, Grades 7–9)

> 175 weeks of lesson notes and fully worked exercises covering the complete PEP (People's Education Press) junior-high mathematics curriculum (grades 7–9, six volumes), with R-generated teaching figures and a complete English translation.

This repository turns the entire PEP junior-high textbook series (人教版初中数学, grades 7–9) into a weekly study system: a definition-first reference (`notes.md`) plus one solved exercise file per week. Content was transcribed week by week against the scanned textbooks in `textbooks/` (files named `7.1`, `8.2`, `9.1`, … = grade 7 vol. 1, grade 8 vol. 2, grade 9 vol. 1, etc.).

## The notes

`notes.md` is a single file organized by **volume (七上/七下/八上/八下/九上/九下) → chapter → section**, collecting only definitions, basic facts and conclusions — 1,712 entries in total. Examples and exercises live exclusively in `homework/`, giving a two-level structure: *quick-reference sheet + exercise book*.

Representative topics across the weeks: positive/negative numbers, powers, linear equations in one variable, supplementary angles, square roots, elimination by substitution, line graphs, congruent triangles, difference of squares, the converse of the Pythagorean theorem, functions, inverse proportional functions, inscribed angles, tangents to circles, and (final weeks, new-edition numbering) similarity, trigonometry, projection and three-view drawings.

## The homework

Each `homework/weekN.md` follows a fixed format:

1. **Toolbox** — a blockquote listing the chapter's definitions/basic facts/conclusions;
2. **Exercises** — textbook exercises and chapter review sets (`### 练习一` …);
3. **Solutions** — complete worked solutions ending with `$\blacksquare$`.

175 weeks total: ~101 weeks of in-text exercises and ~34 chapter-review full sets, plus new-material weeks. Cross-references use bold tags (由**定义 1.1.1**).

## The figures

205 geometric/function figures are generated by R scripts in `codes/` (each outputs a `cairo_pdf` PDF and an `svglite` SVG of the same size), stored in `figures/` and referenced from the Markdown with Pandoc image attributes (`{width=100%}`). The scripts are run manually; there is no build automation.

## Bilingual layout

- `cn/` — authoritative Chinese version.
- `en/` — complete English translation: every one of the 175 weekly files and the notes, line-count-identical with the Chinese originals.
